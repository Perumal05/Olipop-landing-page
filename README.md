# Firebase Studio

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.

## Running Locally

To run this project on your local machine, please follow these steps:

### Prerequisites

Make sure you have Node.js (version 20 or higher) and npm installed on your system.

### 1. Download the Code

First, you'll need to download the project files. You can do this from within Firebase Studio by clicking the download button.

### 2. Install Dependencies

Once you have the code on your local machine, open your terminal, navigate to the project's root directory, and run the following command to install all the required packages:

```bash
npm install
```

### 3. Run the Development Server

After the installation is complete, you can start the local development server with this command:

```bash
npm run dev
```

This will start the application in development mode. You can then view it by opening your web browser and navigating to [http://localhost:9002](http://localhost:9002). The server will automatically reload when you make changes to the code.
