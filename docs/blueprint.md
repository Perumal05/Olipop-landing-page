# **App Name**: Olipop Parallax

## Core Features:

- Customizable Hero Section: Allows users to customize the drink name, description, theme color, and dark/light mode settings for the hero section of the website.
- WebP Sequence Integration: Integrates WebP image sequences for each drink variant as the background of the hero section, creating a smooth parallax scrolling animation.
- Variant Switching: Enables users to switch between different drink variants, updating the text, theme color, and WebP background sequence accordingly with a fade out fade in animation.
- Loading Experience: Provides a loading overlay with the brand logo or name and a horizontal loading bar to ensure all frames are preloaded before displaying the hero section, preventing flicker and enhancing user experience.
- Navigation & Sections: Includes a sticky top navigation bar with links that smooth-scroll to the main sections (Product, Ingredients, Nutrition, Reviews, FAQ, Contact), and indicates the active section while scrolling.

## Style Guidelines:

- Primary color: White (#FFFFFF) to maintain a clean and minimalist aesthetic, consistent with the Olipop brand's design.
- Background color: Near-black (#121212), complementing Olipop's dark mode preference for a sleek, modern feel.
- Accent color: A lighter grey (#A2A2A2), serving as a neutral accent to provide balance and subtlety within the interface. This maintains focus on content without causing unnecessary distraction.
- Body and headline font: 'Inter', a sans-serif known for its clarity and modernity, suitable for both headlines and body text.
- Use simple, monochrome social media icons in the footer and minimal icons in the navigation.
- The hero section uses a full-screen layout with a WebP background and overlay text on the left, variant navigation on the right, and social icons at the bottom.
- Implement smooth parallax scrolling for the WebP sequence in the hero section. Animate updates to drink names, subtitles, and descriptions with fade-in/out effects during variant switches.
